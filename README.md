# Cass Technologies Ltd

The public company website for Cass Technologies Ltd, the UK health and fitness software company behind Macros and Petey.

## Preview locally

Run `python3 -m http.server 8000` from the repository root and visit `http://localhost:8000`. The site serves plain HTML and CSS, with optional canvas interactions. There are no build dependencies.

## Publish

GitHub Pages serves the root of the `main` branch. The production domain is `getcass.com`. All local resources use relative paths so a project-page URL also works before the custom domain is connected.

## Design and assets

The company header uses lowercase TAN Nimbus lettering in offset pink and violet dots. The grey dots respond to pointer and touch across the hero. On desktop, the same grid contains a stationary five-petal bloom that can also be revealed with the keyboard. Each impression briefly holds and fades back to the neutral grid. The portfolio uses the Macros and Petey wordmarks. Fraunces, JetBrains Mono and the Momo Trust Display face in the Macros wordmark are distributed under the SIL Open Font License. Their notices are in `licenses/`.
